# Slide by Slide · 逐页共创 PPT

**别让 AI 一口气吐 30 页再返工。**

先用你的材料做一页真实样张。你确认版式、图文比例和信息密度后，再逐页完成可编辑的 PPT。

手里有一份 30 页的报告，汇报只有 10 分钟。听众离场时应该记住什么？哪一章值得多讲两分钟？Slide by Slide 先和你定下主线与每章用时，再挑最难讲清的一页，用报告里的原图、数字和结论排出样张。你可以当场决定哪张图要放大、哪段话留给口头讲解。样页确认后，后续页面沿用这套标准。

- **沿用你的模板。** 从参考页提取配色、字体和版式，也可以直接从内置的 28 页中文汇报模板中选页。
- **用好手里的原图。** 结果图保留原貌，同一对象跨页复用。现有素材讲不清的地方，再补一张示意图。
- **让结论有据可讲。** 关键数字旁写清比较对象和条件，保留会改变判断的限定，删去空泛的修饰句。
- **改完一页，核对整场。** 插页、删页或换序后，复核页码、章节衔接和总时长。

## 开始使用

**支持本地 Skills 的助手**：下载发布包并解压，把包含 `SKILL.md` 和 `assets/` 的整个 `slide-by-slide` 文件夹放到客户端识别的技能目录。以 Codex 的项目级用法为例，目录为 `.agents/skills/slide-by-slide/`。在新对话中输入：

> 使用 $slide-by-slide，帮我准备一个十分钟的项目提案。听众第一次接触这个主题，请先和我确定每一章讲什么。

**普通 GPT 对话**可上传 [SKILL.md](SKILL.md)、[逐页设计处方](references/page-design.md)、[素材分配与生图](references/visual-assets.md) 和[论证与口头表达](references/claims-and-delivery.md)，再上传自己的模板或[内置可编辑模板](assets/neutral.pptx)。输入“请按这份说明和我逐页制作”。

### 需要安装其他插件或 Skill 吗？

无需另装配套插件或 Skill。逐页设计、素材复用和去防御性写作规则都已随包提供。

- **讨论提纲、撰写文案和逐页提示词**只需文字对话。
- **交付可编辑 PPTX 和真实样页**需要当前环境能创建或编辑 PPTX，并将幻灯片渲染为预览图。
- **生成新插图**时才需要生图工具。已有照片、结果图和模板图形可以直接使用。

## 模板与审核

- 有模板：附上 PPTX 或参考页，说明需要保留的元素、可调整的部分和使用范围。
- 无模板时，打开 16:9 蓝色占位模板，从 28 页中复制合适的版式。第 4–7 页适合背景与比较，第 11–18 页提供四组方法与结果的配对版式，第 19 页适合路线图，第 27 页适合进度与产出。点击文字框输入内容，用自己的素材替换浅色图片区。封面、目录和章节页按汇报需要选用。
- 想先省下生图时间：说“先讨论分镜，再预览最难的一页”。想按页审核：说“本页通过后再做下一页”。已有完整要求：说“资料齐全，按这份提纲制作前三页”。
- 编号方式和备答页范围在规划时确定。

## 设计示例与规则

入口文件规定两种模板路径和固定色板。逐页设计处方包含十种版式、七项单页指令及一份虚构的完整示例；素材指南说明何时使用用户原图、画可编辑图表、复用资产或生成插图。
