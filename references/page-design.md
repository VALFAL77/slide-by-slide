# 逐页设计处方

先用一句话写出观众看完本页能回答的问题。按答案中的关系选构图；比例指正文区，按模板和图形长宽调整。相邻页如果在回答同类问题，保留同一阅读顺序；换一种论证任务时再换构图。

| 页面任务 | 怎样安排内容 | 看预览时查什么 |
|---|---|---|
| 开场或主张 | 标题占左约 55%，右侧只放一个能辨认主题的主视觉。横图有天然留白时也可满幅。 | 在缩略图上能否先读到题目？主体有没有被标题或裁剪切断？ |
| 背景与选择 | 三栏约 3:3:4，分别放需求、备选、选择依据。最后一栏只留下后文要用的原理或约束。 | 遮住栏名后，能否从材料看出为什么选这一项？ |
| 演进或差异 | 按同一比较维度横排 2–3 个对象。变化写在两框之间。若要同时介绍可用方法，放底部通栏。 | 所有对象的图是否同尺度？箭头表示时间还是结构变化？ |
| 一一对应 | 两栏等宽，中间留窄通道。同一行放一对意见与回应、条件与后果或对象与特征。 | 每条对应能否顺着一根线读完？多对多时改成点阵。 |
| 方法与过程 | 三步各写输入、操作和输出，箭头标明传递的量或材料。复杂系统单独用约 2/3 宽的结构图，另一侧解释关键约束。 | 听众能否从第一步走到最后一步？有反馈时是否画出回路？ |
| 初步验证与后续计划 | 左侧约六成放原始结果图。右上可放 3～4 个关键数字，带单位、对照和条件，有几项依据就用几项。右下写下一次实验或行动及评价指标。 | 每个数字能追溯到哪张图或哪条记录？下一步用什么判断成效？ |
| 场地、器材与信息链路 | 先列起点、终点、连接类型和方向，再按来源—处理—记录摆放。主图占上半部或左侧大区，局部细节用原图裁切。 | 从任一端口能否追到去向？实线、虚线及其图例是否一致？ |
| 比较、矩阵或现状 | 列是要做判断的维度，行是对象。首列固定，关键字段控制在一至两行。保留必要限定，详细出处进备注。 | 删掉哪一列不影响决策？典型样例和总体统计是否区分？ |
| 计划或路线图 | 并行任务用泳道，时间段用甘特图，串行依赖才画箭头。已完成、拟开展和可选工作分别标记。 | 时间、任务、产出能否在同一行找到？状态是否被写成结果？ |
| 收束与决策 | 结论占主位，下面给支持它的最小证据与行动。若仅需致谢，复用封面版式。 | 听众能否说出要记住或决定的那一件事？ |

## 制作一页前，填这七行

1. 页名、所在章节、预计讲述秒数和承接句。逐页时间之和应与整场预算相合。
2. 观众的一句话回答：说出发现或行动，注明依据的位置。涉及推断时，判断哪个条件必须和结论一起上屏。
3. 版式：选上表哪一类，主区与辅区的比例是多少？
4. 阅读动线：第一眼看到什么，第二眼去哪，箭头或对齐表示什么关系？
5. 每区实字：写出每个框的标签、上屏短句、数字与单位、底部结论。若用红色，逐字写明要标红的词。出处与额外解释按需进备注。
6. 逐图指令：标出四类图中的来源、资产编号、画幅和用途。代码图写变量与关系，结果图写原件定位及裁剪范围，用户素材写使用方式。新生 AI 图给出完整英文提示词和展开后的对应后缀。沿用已审图标只填编号。
7. 验收：列一个本页最容易画错或讲错的细节。把标题和结论连起来念一遍，删去重复的自我评价，检查删字后原判断是否仍然成立。写下通往下一页的问题。

简短页可以合并字段，模板样式和已确认决定直接引用。正文区先排主图与结论，再放解释。标题、正文与脚注共用对齐线。同级元素统一内边距和行距。先按缩略图看焦点与组块，再按播放大小看文字和轴标；有遮挡、细字或多条箭头相交时先改构图。

## 方法与初步验证成对排页

复用进度条时，依模板以颜色或加粗区分当前步骤。若任务约定全页只在底部结论使用红色，进度条改用深蓝加粗，其余步骤用灰色。

同一主题需要讲清做法和验证时，用连续两页。内置方法页的标题栏下方左侧放小标题条，右侧列整体进度并突出当前项。三个并列虚线框内放图与短句，每步名称嵌在框底蓝色标签中，框间箭头说明传递的结果。一般比较页和结果页的分区标签则嵌在框顶。验证页沿用同一主题，按上表“初步验证与后续计划”排。下一主题沿用这对版式，便于观众比较。对照条件一致且结果相近时，清楚写出“在该条件下，两种方案表现相近”。只有能够区分各环节贡献的证据才支持改善归因。

## 完整示例：两场活动的比较（虚构）

前页交代试办安排，本页回答“下一场优先改善哪个环节”。资料表给出报名与到场人数：甲场 20 人报名、15 人到场；乙场 10 人报名、8 人到场。页面标题写“先核对缺席原因”。左侧 60% 用原生图表比较到场率 75% 与 80%，两组使用同一 0–100% 量程，标签保留 15/20、8/10。右上写“合计 7 位报名者未到场”，右下列下一步“询问未到场者”。不从两组小样本推断活动优劣。下一页转到回访安排。本页复用报名表数据，新生成插图数为零。

## 常见返修

“太满”时先移出次要列、重复标题和背景解释，再考虑拆页；“没主次”时让主证据占最大面积，削弱次要边框；“连接和文案对不上”时回到端点表重排节点；“颜色变了”时回到本稿色板映射；“像换了一个物件”时查找已审素材及其裁切版本。只重渲染改动页及受共享元素影响的页。
